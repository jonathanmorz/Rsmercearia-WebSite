O **Rsmercearia** é um protótipo de sistema web desenvolvido para simular a vitrine e o gerenciamento de uma mercearia/comércio local. 

> 📌 **Nota histórica:** Este foi o meu **primeiro protótipo de aplicação web**, criado no início da minha jornada no desenvolvimento de software. Ele reflete meus primeiros passos na integração entre front-end e lógica de back-end em PHP.
